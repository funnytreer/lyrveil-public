## 判定

- **通过**：元数据完整，播放/暂停/切歌事件可靠，时间线可用于秒级歌词同步。
- **部分通过**：能识别歌曲，但缺少时长、时间线或部分事件；需要播放器专用校准。
- **不通过**：没有 GSMTC 会话或会话内容无法稳定识别；再评估 UI Automation 等兜底方案。

`*` 表示字段由词间实验性本机进度通道提供。网易云音乐 3.1.37.205354 已完成播放推进、暂停、连续拖动、切歌、短暂断线续时和精确歌曲 ID 的实机/自动化验证。v10 在此基础上新增 3.1.38 的 `playingProgress.current` 首次锚点，v11 增加 750 ms 跳转过渡保护和连续无效样本门槛。v12 会按每次跳转测量并固定扣除逻辑读头领先量，但实机发现网易云的累计输出计数会在个别跳转中成块跃进，使测量值只能偏小。v13 因此同时强制采用“绝对进度不得快于跳转后墙钟”的单向下界，并额外保留 80 ms 输出缓冲安全余量；三者只在本次跳转时计算一次，不在正常播放中持续重调，也不把累计量当成歌曲绝对位置。网易云音乐 3.1.38.205386 已通过首次位置、双 ID 计数对照、静态协议、JavaScript 语法和离线边界验证，实际设备的播放/暂停/连续拖动听感仍标记为待验收。通道未启用、连接失败或播放器版本不兼容时，会退回系统媒体会话或从最后可靠锚点本地续时，并在界面中明确提示同步能力。
