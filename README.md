# 词间 · Lyrveil

一个低干扰的 Windows 第三方桌面歌词应用。`Lyrveil` 由 lyric 与 veil 组合而来：歌词像一层很轻的薄幕，需要时出现，不需要时隐去。项目内部仍使用开发代号 `LyricsXQuiet`，Windows 代码为独立重写。

## 初版已经可以做什么

- 通过 Windows GSMTC 识别 QQ 音乐、网易云音乐、酷狗音乐、Apple Music 和 Spotify；浏览器网页的视频与音频会被忽略。具体进度与跳转能力取决于播放器版本及其系统播放控件设置。
- 以 Windows 事件为主监听播放、切歌和时间线变化，并按同步能力做低频自适应复查；播放器提供有效时间线时，手动拖动进度会立即重新校准歌词。Apple Music 的 seek 过渡会隔离同一会话的旧位置帧，不使用其他播放器的时间锚点。
- 多个受支持播放器同时打开时，优先实际出声或明确正在播放的会话；短暂的音频尾音只用于稳定选择，不会把真实暂停改回播放。
- 从本地缓存或已启用的网络歌词源获取同步歌词，也可手动导入 `.lrc` / `.lrcx`。
- 可展开当前歌曲的多个匹配版本，按歌名、歌手、专辑与时长手动选择；首选项同时说明“歌手相符 / 专辑相符 / 时长差 / 逐字 / 来源”等推荐依据。选择结果会与当前歌曲绑定并在下次播放时优先使用。
- 歌词统一保存到“音乐/Lyrveil Lyrics”文件夹，可在设置中打开或更改位置。
- 支持逐行编辑正则表达式，清理作词、作曲、制作人等杂乱信息；无效规则会指出原输入中的精确行号，过滤只影响显示，不改写原始文件。
- 歌词来源或歌词文件明确标记为纯音乐时自动隐藏悬浮歌词，不把普通的“未找到歌词”误判为纯音乐。
- 解析普通 LRC、`offset`、相同时间戳翻译行和增强 LRC 逐字时间标签。
- 在桌面显示内容尺寸的透明悬浮窗，不创建全屏透明输入层。
- 锁定时真正点击穿透，并且不激活、不出现在任务栏。
- 鼠标经过时淡出整个悬浮层；解锁后可拖动并记住位置。
- 可在设置中一键恢复到屏幕下方的默认居中位置；解锁拖动时会暂时停用经过隐藏。
- 只调节深色背景的透明度，歌词文字和青色进度始终保持清晰。
- 可选择系统字体、调节字号，并分别设置歌词色、进度色和背景色；颜色不改变文字透明度。
- 提供系统托盘、快速调节面板和完整设置窗口。
- “关于”页的安全诊断摘要隐藏本地播放器程序的完整路径，也不包含歌名、歌手、歌词或歌词路径。
- 使用以“词”为主体的双色图标，薄荷青覆盖表示逐字歌词的同步进度；包含多尺寸 PNG 与 Windows ICO。
- 完整应用默认不随 Windows 登录启动；可在轻量后台监听器和保留播放器原外观的组合快捷方式之间选择。

## 运行

需要 .NET 8 或更新的 SDK。脚本优先使用 `.tools/dotnet` 中的便携式 SDK，也支持系统安装的 SDK；只有 .NET 运行时不能用于构建。直接运行：

```powershell
# 正常模式：常驻托盘，监听当前播放器
.\scripts\run-app.ps1

# 内置歌词演示
.\scripts\run-app-demo.ps1

# 演示并打开快速调节面板
.\scripts\run-app-demo.ps1 -ShowPanel

# 使用 Release 构建运行
.\scripts\run-app.ps1 -Configuration Release
```

左键单击托盘图标打开快速面板，右键可显示/隐藏歌词、进入完整设置或退出。

## 歌词来源与手动选择

- **LRCLIB** 是公开、默认启用的网络歌词源，无需登录。
- **QQ 音乐、网易云音乐和酷狗音乐** 是实验歌词源，可在设置中分别关闭。它们依赖的网络接口可能变更、限流或因地区与版权状态返回不同结果，不应视为稳定服务承诺。
- **Musixmatch** 目前尚未配置，不会发起网络请求。
- 自动匹配会并行汇总已启用来源，先校验歌名、歌手、专辑、版本与时长，再按设置决定是否优先真实逐字歌词。在快速面板展开“选择歌词”后，单击某个版本即可固定使用，并保存到歌词文件夹，以后再播放同一首歌时优先读取。
- 本地缓存和手动导入不依赖网络歌词源；某个实验来源失败时，其他来源和已保存歌词仍可继续使用。
- 自动匹配使用较少的高相关候选，并将跨来源搜索的总等待限制为 6 秒；手动浏览候选最多等待 30 秒。超时来源不会阻断已经完成的来源；候选列表会标明暂时不可用的来源。
- 本地缓存先显示，再检查需要的来源升级。新歌词和手动选择也先显示再保存；保存失败会明确提示本次可用但未保存。缓存使用同目录临时文件替换，避免失败写入破坏旧选择。
- YRC/KRC 的真实词持续时间会保留到增强 LRC 缓存中；普通 LRC 或缺少词结束时间的旧缓存继续使用插值。

**播放器识别与歌词来源彼此独立。** 播放器识别只负责从 Windows 获得当前歌曲和播放进度；歌词来源只负责根据歌曲信息搜索歌词。例如，QQ 音乐播放的歌曲可以使用 LRCLIB 或网易云音乐返回的歌词；启用某个歌词源也不要求安装或运行同名播放器。

## 播放器伴随启动

词间提供两种可选方式，完整应用都不会直接随 Windows 登录启动：

1. 手动运行一次词间，打开“完整设置 → 常规”。
2. 选择“后台监听播放器”时，会注册一个无界面的小型登录监听器；从播放器原来的任意入口启动都能跟随词间。
3. 选择“组合快捷方式”时，不运行登录监听器；应用会在桌面创建名称和图标与原播放器一致的替代入口。
4. 两种方式都可同时选择 QQ 音乐、网易云音乐、酷狗音乐、Apple Music 和 Spotify。

自动检测同时兼容普通桌面程序和 Microsoft Store 版 Apple Music、Spotify；商店应用通过其应用标识启动，不直接运行受保护目录中的程序文件。

组合快捷方式模式在播放器退出后只做约 2 秒的快速重启探测；检测到播放器更新程序时，词间隐藏歌词并最多等待 5 分钟，播放器重启后继续运行。后台监听模式在发起启动后会确认词间主实例确已运行；启动失败或短时退出时按 2、4、8 秒逐步退避，最长 30 秒后重试，稳定运行 30 秒后重置失败计数。手动启动词间时不会套用自动退出规则。

## 工程结构

- `src/LyricsXQuiet.Core`：播放模型、LRC 解析、歌词时间轴、缓存、网络歌词源和设置。
- `src/LyricsXQuiet.Platform.Windows`：GSMTC 播放器监听与 Win32 窗口互操作。
- `src/LyricsXQuiet.App`：WPF 悬浮窗、托盘、快速面板和完整设置。
- `tools/PlaybackProbe`：独立播放器兼容性探针。
- `tools/CoreSmokeTests`：不依赖第三方测试框架的核心冒烟测试。
- `prototype`：早期可交互设计原型。
- `design/icon`：图标矢量源文件与视觉预览；可用 `scripts/generate-icon-assets.ps1` 重新生成 Windows 图标资源。

完整产品状态、交互规则、视觉令牌、隐私边界和发布验收矩阵见
[`docs/product-design-specification.md`](docs/product-design-specification.md)。

## 验证

```powershell
.\scripts\verify.ps1
# 已恢复依赖的离线环境可用：.\scripts\verify.ps1 -NoRestore
# 没有交互桌面的 CI 可用：.\scripts\verify.ps1 -SkipUi
```

统一入口会构建解决方案并依次执行 Core、Platform、歌词升级、悬浮窗/快速面板四组验证。Core 测试包含缓存失败降级、原子替换、异步目录访问、来源失败、版本去重、搜索时限和词持续时间的回归场景，默认不访问在线歌词服务。

## 初版边界

- LRCLIB 是当前公开默认源；QQ 音乐、网易云音乐和酷狗音乐为可单独关闭的实验源，上游接口变更时可能暂时不可用；Musixmatch 尚未配置。
- 当前播放器采用明确白名单，只读取五个受支持桌面音乐软件的 GSMTC 会话；Chrome、Edge、Firefox 等浏览器会话不会进入歌词匹配。
- 通常只有播放器向 Windows 发布有效时间线时才能精确同步；网易云可选用词间自带的实验性本机进度通道作为补充。词间会区分“精确同步”“本地计时”和“未获得播放进度”，不会把仅识别到歌名误报为精确同步。
- 网易云音乐原生会话缺少时间线时，可完全退出播放器，再从词间生成的组合快捷方式启动，尝试启用内置实验性进度通道。该通道只绑定本机，不安装插件、不修改网易云目录，也不保存播放记录；若版本更新导致通道不可用，会退回系统媒体会话或从最后可靠锚点续时。网易云 3.1.37.205354 的播放、暂停、切歌和手动拖动已完成实机验收。
- 尚未制作安装包、代码签名、自动更新和全局快捷键。
- 任何网络歌词源失败时，应用会继续使用本地缓存或手动 LRC，不影响播放器本身。

LyricsX 是独立项目。本项目不复用 LyricsX 名称、图标或 macOS 源码文件。
